# SUBBHU Wallpapers & Ringtones

A native Android wallpaper and ringtone application with a companion website.

## Current foundation

- Kotlin Android application
- Initial navigation-free home screen
- GitHub Actions debug APK build
- Android SDK configured in the cloud workflow

## Planned

- Wallpaper downloads and system wallpaper APIs
- Native live wallpaper service
- Ringtone and audio-setting APIs
- Supabase catalog, authentication and favorites
- Secure administrator dashboard
- Companion website and advertising

Planned features are not implemented until their code and tests are complete.

## Build

The GitHub Actions workflow builds a debug APK and publishes it as an artifact.
